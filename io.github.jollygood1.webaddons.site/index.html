Eclipse Web Addons

This address is an Eclipse update site. It is meant to be opened from Eclipse, not in a browser.

  1. In Eclipse: Help > Install New Software...
  2. Press Add... and enter this page's address as the location:
    https://jollygood1.github.io/eclipse-web-addons/
  3. Select Syntax Colour Themes for Web, File Icons for Web, or both, and follow the dialog. The jars are not signed, so Eclipse asks whether to trust them.
  4. Restart Eclipse. The pages are under Preferences > General > Appearance.

Source, documentation and licences: github.com/JollyGood1/eclipse-web-addons
